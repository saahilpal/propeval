# ADR-004: Non-Compensatory 3-Tier Evaluation & Cross-Family Calibrated Judges

**Status:** Accepted | **Date:** 2026-11-19

* **Decision:** Reject single composite 0–100 scores and uncalibrated Likert LLM judges. Enforce a **Non-Compensatory 3-Tier Evaluation Pipeline**: Layer 1 deterministic code/metamorphic oracles (hard gates), Layer 2 versioned property fact-grounding verifier (hard gate), and Layer 3 cross-family binary rubric judges with position swapping (`(A,B)` + `(B,A)`) calibrated on human golden sets (Cohen's $\kappa \ge 0.70$, Rogan–Gladen / PPI++).
* **Requirement:** Satisfies FR-09–FR-13 (reliable extraction, RERA grounding, DNC safety, zero circular validation) and NFR-11 (judge calibration floor).
* **Alternatives:** (1) **Single Composite 0–100 Score** (weighted average across dimensions); (2) **Uncalibrated 1–5 Likert LLM-as-a-Judge**; (3) **Embedding Cosine Similarity / BERTScore** against reference answers; (4) **Large Multi-Judge Panels (5+ models)**.
* **How the alternatives work:** Composite scoring averages all metrics into one KPI. Likert judges prompt an LLM to rate 1–5. BERTScore/cosine similarity compare embedding vectors of candidate vs reference responses. Large panels majority-vote across 5+ LLMs.
* **Selection reasoning:** [Real World Voice EQ Bench (2026)](https://arxiv.org/abs/2607.14846) proves voice capabilities are orthogonal—averaging them lets a +10% tone gain mask a legally dangerous RERA or DNC failure. BERTScore misses numeric swaps (`₹1.2 cr` vs `₹2.1 cr`; [FinNuE, 2025](https://arxiv.org/html/2511.09997v1)), and cosine similarity produces arbitrary rankings ([Steck et al., 2024](https://arxiv.org/abs/2403.05440)). Naive LLM judges suffer position, verbosity, self-preference, and cross-lingual biases ([Zheng et al., 2023](https://arxiv.org/abs/2306.05685); [Panickssery et al., 2024](https://arxiv.org/abs/2404.13076)). Deterministic code oracles + cross-family calibrated binary judges eliminate circular validation and keep CI gates fast (<50 ms for Layer 1).
* **Rejected alternatives:** Single composite scores hide critical regressions; Likert scales collapse to `3` with low inter-rater reliability; embedding similarity is blind to real-estate numbers; large panels add cost while correlated errors inflate apparent confidence ([arXiv:2605.29800, 2026](https://arxiv.org/html/2605.29800v1)).
* **Trade-offs:** We gain auditable, non-compensatory release safety and honest uncertainty reporting. We lose a single marketing-friendly "score" and require domain experts to label 30+ golden anchor transcripts per rubric.
* **Failure modes:** Criteria drift as engineers discover new failure modes ([Shankar et al., 2024](https://arxiv.org/abs/2404.12272)); indirect prompt injection inside transcripts hijacking the judge (mitigated via randomized XML nonce framing + JSON Schema); per-variant judge calibration drift if V2 style diverges sharply from V1.
* **Cost:** Upfront engineering of deterministic Indian currency/RERA verifiers + 2–3 hours of human labeling per golden calibration set + $2\times$ judge calls for position-swapped pairwise checks.
* **Revisit conditions:** Adopt a small 3-model cross-family PoLL jury ([Verga et al., 2024](https://arxiv.org/abs/2404.18796)) only if a single cross-family judge fails to hold $\kappa \ge 0.70$ on Hinglish tone/objection rubrics after prompt refinement.
