# ADR-003: Hybrid FSM / Agenda-Gated + LLM Surface Realization Conversation Simulator

**Status:** Accepted | **Date:** 2026-11-19

* **Decision:** Build PropEval's multi-turn buyer simulator as a **Hybrid FSM/Agenda + LLM Surface Realization Engine** backed by a post-rollout **Simulator-Fidelity Auditor** that quarantines invalid rollouts, paired with domain-aware 8 kHz Indian ASR perturbation and tool-fault injection.
* **Requirement:** Satisfies FR-05 (realistic Hinglish multi-turn buyer simulation), FR-06 (paired reproducibility across V1 vs V2), and FR-07 (ASR noise & tool-fault resilience).
* **Alternatives:** (1) **Pure LLM Persona Simulator** (free-form role-play prompt); (2) **Scripted / Deterministic Replay** (fixed user utterances); (3) **Pure Template FSM** (no LLM).
* **How the alternatives work:** Pure LLM simulators receive a persona paragraph and generate turns freely. Scripted replay feeds pre-recorded user turns regardless of agent responses. Pure FSMs emit hard-coded template strings per dialogue state.
* **Selection reasoning:** Independent benchmark audits prove pure LLM simulators suffer **40–47% user-simulator error rates** (`τ²-Bench`, [Barres et al., Jun 2025](https://arxiv.org/abs/2506.07982)), RLHF **assistant/benevolence bias** ([Jeong et al., Sep 2026](https://arxiv.org/abs/2609.00608)), and **worst calibration to Indian English speakers** ($ECE=18.9$ vs $13.0$; [Seshadri et al., Jan 2026](https://arxiv.org/abs/2601.17087)). By letting a deterministic FSM control *when* the buyer reveals `"1.2 cr"`, challenges RERA possession, or demands DNC—while the LLM only renders natural Hinglish phrasing for that single directive—we preserve Hinglish realism while eliminating premature slot-dumping and instruction drift.
* **Rejected alternatives:** Pure LLM simulators distort Prompt V1 vs V2 comparisons (cooperative simulators let robotic prompts pass 90%+). Scripted replay breaks immediately whenever Prompt V2 asks questions in a different order. Pure template FSMs miss Hinglish code-switching diversity and pragmatic nuance.
* **Trade-offs:** We gain high reproducibility, zero goal drift, and quarantine protection against simulator noise. We lose effortless zero-shot scenario authoring—every scenario requires an explicit YAML FSM agenda spec.
* **Failure modes:** Overly rigid FSM transitions can miss valid unexpected agent digressions; the surface-realizer LLM can still leak persona instructions or switch out of Hinglish (mitigated by `SimulatorFidelityAuditor` quarantine).
* **Cost:** Higher upfront YAML authoring effort (~15–20 min per complex scenario) plus 1 lightweight simulator LLM call per turn (~$0.002/turn) and 1 post-call fidelity check.
* **Revisit conditions:** Revisit if specialized fine-tuned Indic buyer-simulator models emerge with audited simulator error rates <5% and verified calibration ($ECE < 5$) on Indian Hinglish telephony transcripts.
