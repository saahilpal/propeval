# ADR-005: Paired Statistical Gating, Two-Tier Sample Sizes & Anti-Pseudoreplication

**Status:** Accepted | **Date:** 2026-11-19

* **Decision:** Enforce paired experimental design using **Exact Binomial McNemar's test + Newcombe Paired Wilson CIs** (binary), **Wilcoxon signed-rank + two-stage cluster/hierarchical BCa bootstrap** (continuous/ordinal), **`pass^k`** consistency over $K=3\text{–}5$ repeated trials, **Holm-Bonferroni** correction on ship guardrails, and strict **Two-Tier Gating** ($N=20$ labeled `SMOKE_TEST_UNDERPOWERED`; $N=50\text{–}100$ required for statistical release claims).
* **Requirement:** Satisfies FR-14, FR-15 (defensible regression gating) and NFR-10 (mathematical refusal to emit false significance claims at small $N$).
* **Alternatives:** (1) **Unpaired two-sample $t$-test / two-proportion $z$-test**; (2) **Asymptotic CLT / Wald intervals at $N=20$**; (3) **Naive pooling of $N \times K$ trials into $n=100$**; (4) **No statistical testing (raw pass-rate diff only)**.
* **How the alternatives work:** Unpaired tests compare V1 and V2 means ignoring scenario-level covariance. CLT/Wald intervals approximate binomial variance normally. Naive pooling treats $K$ repeated runs of the same scenario as independent samples. Raw diffs ship whenever `V2 > V1`.
* **Selection reasoning:** Pairing removes between-scenario difficulty variance ($\operatorname{Var}(\bar{D}) = (\sigma_X^2 + \sigma_Y^2 - 2\rho\sigma_X\sigma_Y)/N$), cutting required $N$ up to $4\times$ ([Evan Miller, 2024](https://arxiv.org/html/2411.00640v1)). Asymptotic CLT intervals systematically under-cover below a few hundred datapoints ([Bowyer et al., ICML 2025](https://arxiv.org/abs/2503.01747)). Naive trial pooling inflates Type I error past **45%** ([Saravanan et al., 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7906290/)). Exact power analysis proves $N=20$ has 80% power only for +36.6 to +53.4 pp jumps—forcing honest Two-Tier separation.
* **Rejected alternatives:** Unpaired tests throw away statistical power; CLT/Wald intervals produce misleadingly tight error bars; pooled trials create catastrophic false positives; raw diffs ship random LLM sampling noise.
* **Trade-offs:** We gain mathematically defensible ship decisions that withstand scrutiny from quantitative founders (e.g., Tushar Khustule). We lose the illusion of "statistically significant wins" on quick 20-scenario PR runs and pay $3\text{–}5\times$ token cost on Tier-2 $K=3\text{–}5$ release gates.
* **Failure modes:** BCa bootstrap can return `NaN` on heavily tied small-$N$ discrete rubrics (mitigated by automatic fallback to `percentile` bootstrap); multi-turn simulator divergence slightly weakens pairing after Turn 1 (mitigated by paired seeds + FSM agenda control).
* **Cost:** Negligible compute (SciPy/statsmodels run in <100 ms); $N=100, K=3$ nightly release runs cost ~$8–$15 in LLM API fees (mitigated by mSPRT early-abort on catastrophic harm).
* **Revisit conditions:** Adopt Bayesian hierarchical Beta-Binomial / Dirichlet-Multinomial posteriors (`bayes_evals`) as the primary UI view if engineering teams prefer direct probability statements ($P(\Delta p > 0 \mid \text{data})$) over frequentist $p$-values.
